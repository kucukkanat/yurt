## gestures: Touch, gestures, interaction feel and haptics
- [must] Pointer Events as the single input model; gestures only for pointerType 'touch'

- [must] Passive listeners by default; passive:false only where you truly cancel scrolling

- [should] Swipe completion: distance OR a short fast flick, with velocity from recent samples and momentum projection
- [should] Swipe-to-act rows (reply / archive / delete): follow the finger, resistance past the threshold, haptic tick on arming
- [should] Rubber-band resistance instead of hard clamps
- [should] Native momentum via CSS scroll-snap for pagers, carousels and swipe-to-reveal actions
- [must] Edge swipes (drawer) vs the system's back/forward gestures
- [should] System Back closes the top layer; swipe right dismisses full-screen panels
- [should] Swipe down to dismiss sheets (touch events, only when content is at the top)
- [must] overscroll-behavior: no whole-app bounce, no scroll chaining, no surprise browser pull-to-refresh
- [should] Custom pull-to-refresh (needed in iOS home-screen apps), or better, auto-sync
- [must] Long-press context menus that replace the browser's callout
- [should] Desktop: right-click menus, hover action bars and keyboard access, without stealing native menus
- [should] Drag & drop on touch: pointer-driven reordering with a handle (or long-press pickup), autoscroll, keyboard fallback
- [should] Pinch-zoom, pan and double-tap zoom in image viewers (touch + trackpad)

- [must] Hit targets sized by pointer type (44pt iOS / 48dp Android), with invisible hit-area expansion
- [should] Haptics on Android: the Vibration API behind a user setting, reduced motion and activation checks
- [nice] Haptics on iPhone: the <input type=checkbox switch> label trick (iOS 18+, real taps only since 26.5)
- [must] User activation rules: on touch, gated work belongs in pointerup/click, not pointerdown
- [should] Unlock audio on the first tap anywhere (ringtones, notification sounds, calls)

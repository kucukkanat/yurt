Keycap chip that shows a keyboard shortcut; put one next to (or inside) every primary action.

```jsx
<Kbd keys="mod+k" />
<Kbd keys="enter" tone="onAccent" size="sm" />
```

- Tones: `default`, `onAccent` (inside primary buttons), `onAgent` (inside volt), `inverse` (dark chrome).
- Aliases render as glyphs: `mod`→⌘, `shift`→⇧, `enter`→↵, `esc`→Esc.
